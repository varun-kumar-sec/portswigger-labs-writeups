# Access Control Labs

## 📌 Overview
This section contains PortSwigger Web Security Academy labs related to Access Control vulnerabilities.

These labs demonstrate how improper authorization mechanisms can allow attackers to:
- Access administrative functionality
- Escalate privileges
- Bypass restrictions
- Access unauthorized resources

---

## 🛠 Skills Practiced
- Forced browsing
- Role-based access control testing
- Privilege escalation
- URL manipulation
- Parameter tampering
- JavaScript route analysis
- Burp Suite request modification

---

## 📂 Labs Completed

- [x] Unprotected admin functionality
- [x] Unprotected admin functionality with unpredictable URL
- [x] User role controlled by request parameter
- [x] User role can be modified in user profile
- [x] User ID controlled by request parameter
- [x] URL-based access control can be circumvented
- [ ] Method-based access control can be circumvented
